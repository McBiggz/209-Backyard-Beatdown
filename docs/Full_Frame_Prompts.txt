HOW TO USE
1. Make the STYLE REFERENCE first (see below) and keep it.
2. New ChatGPT chat per wrestler. Attach his character model + the STYLE REFERENCE. Paste the SETUP prompt with his name and look line filled in.
3. When it says "Ready", paste ONE sheet at a time (copy the whole sheet block, not just the letter).
4. Check each sheet: right poses, right order, same size as before, still him. If not, "redo frame X" or start a fresh chat.
5. Download the real image (not a screenshot) and send it to Claude with his name and the sheet letter.

STYLE REFERENCE (do this once, before anyone else)
Pick the look you want for the whole game. Redraw Viral's fighting stance (and one new guy's) in that style using his character model + this line:
"Redraw this wrestler as a single fighting-stance sprite in true 16-bit SNES fighting-game pixel art: visible square pixels, thin even black outline, limited palette of 16-24 colors, 2-3 flat shading tones per color, no gradients or airbrushing, bold readable shapes. Solid magenta background (#FF00FF)."
When you like it, that image is the STYLE REFERENCE you attach to every chat.

SETUP PROMPT (paste once per wrestler chat)
============================================================
You are making sprite sheets for my 16-bit wrestling game. Do not draw anything yet. Read these rules and reply only "Ready."

WRESTLER: [NAME]
LOOK: [PASTE HIS LOOK LINE]

The attached images are (1) his character model and (2) the STYLE REFERENCE sheet. Every sheet must match the STYLE REFERENCE's art style exactly, and match his character model for his face, body, gear and colors. Always draw each sheet completely new; never reuse or edit an earlier image.

RULES FOR EVERY SHEET:
1. True 16-bit SNES pixel art: visible square pixels, hard edges, no blur, no gradients, no airbrushing. Limited palette (about 16-24 colors). Shading with 2-3 flat tones per color. Thin, even black outline.
2. Same size in every frame and every sheet: the same height and head size as his character model. Never shrink him on later sheets.
3. ONE row of frames, left to right, in the exact order listed. Wide landscape image. Clear magenta space between frames; frames never touch.
4. Standing frames share the same baseline (feet on the same line).
5. Draw ONLY him. Any opponent is invisible: pose him as if the other person were there.
6. Side view, facing RIGHT unless a frame says otherwise.
7. Solid flat magenta background (#FF00FF). No border, floor, shadow, motion lines, effects, numbers, labels or text (except writing on his own gear).
8. Every frame must be a different pose. Never repeat a pose.
9. If I say "redo frame X", redraw only that frame and keep everything else identical.
